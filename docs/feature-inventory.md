## 1. 产品定位与能力分层

Zeus 是**AI 原生的多 Agent 团队运行时**：给一个本地目录即可使用，用户正文不出本机，外部能力只经三条通道接入——**MCP**（连接外部系统）、**Skill**（能力与权限声明）、**A2A**（跨 Agent 协作）。
